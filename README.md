# JavaScript Essentials Practice

A collection of small browser-based JavaScript exercises. Each folder contains an HTML page and a script that practises one core concept, from scope and control flow to DOM manipulation and array methods.

## Exercises

| Folder | What it practises |
|---|---|
| `SampleFolder/Scope` | Global, block and function scope with `var`, `let` and `const` |
| `controlFlow` | Conditional logic with the ternary operator |
| `calculateArea` | Reading form input and calculating a rectangle's area |
| `DebugCode` | Debugging with the `debugger` statement in browser DevTools |
| `employeeDetails` | Array methods `map`, `filter`, `reduce` and `find` on employee records |
| `TodoList` | DOM manipulation and events: add tasks, mark them complete, clear completed or all tasks |
| `speedAnalysis` | Typing speed test: timing with `Date`, word counting with regex, words-per-minute calculation |
| `productSurvey` | Feedback form: reading form fields and handling click and keyboard events |
| `healthArticle` | Page and JSON data (`health_article.json`) for a health articles page; the script is still empty |

The repository also contains `jbbmo-Introduction-to-Git-and-GitHub`, a reference to a separate Git exercise repository.

## Tech stack

| Area | Technologies |
|---|---|
| Language | JavaScript (ES6+) |
| Markup | HTML5 |
| Runtime | Web browser |

## Getting started

No build step or dependencies. Open any exercise's `.html` file in a browser (or serve the folder with a static server such as the VS Code Live Server extension) and use DevTools to see console output.

```bash
git clone https://github.com/martinab121/javaScriptEssential.git
cd javaScriptEssential
# open e.g. TodoList/todo_list.html in your browser
```
